# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–14 приняты пользователем и отправлены в `origin/main`.
Последний подтверждённый commit — `0a0d72f`, предыдущая проверка пользователя
на Windows — `npm test` 121/121 PASS. Это сведения предыдущего этапа.
Этап 15: PWA для OWNER/ADMIN/TRAINER, запуск через `/login`, установка из
`/application`, отдельный обезличенный offline-экран, обновление после закрытия
всех окон. Текущий патч ожидает локальной приёмки. Правила — [PWA.md](docs/PWA.md).
Реальная доставка системного Push и установка на телефоны не подтверждены.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000/login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
