# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–16 приняты пользователем. Последний подтверждённый commit — `fa178cb`,
отправлен в `origin/main`. Предыдущий полный прогон контейнера этапа 16 — 153/153 PASS;
это не результат новой проверки и не подтверждение полного локального прогона дополнения.
Этап 16: публичный прайс из CRM, управление публикацией и удалением тарифов OWNER,
магазин с фото и удалением товаров с сохранением заказов, SEO и единый адрес `/`.

Этап 17 реализован в патче, ожидает проверок PostgreSQL и локальной приёмки:
публичное расписание `/schedule.html`, только просмотр групповых занятий, явно
выбранных OWNER. Публичное имя тренера задаётся отдельно. Персональные занятия,
клиенты, вместимость, помещения и внутренние причины не выводятся.
Новая миграция — `20261025110000_public_schedule`. Применение:
[DEVELOPMENT.md](docs/DEVELOPMENT.md#этап-17-публичное-расписание).

Домен не выбран, SEO_INDEXABLE по умолчанию false. Реальные материалы клуба,
телефоны, данные тренеров и юридические тексты ожидаются. Онлайн-запись и онлайн-покупка абонементов не подключены. В магазине по-прежнему
только самовывоз и оплата при получении. Установка PWA на телефоны/Safari и
системная доставка Push не подтверждены. Платформа не объявляется готовой к production.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000; вход сотрудников — /login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
