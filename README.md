# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–17 приняты пользователем. Последний подтверждённый commit — `de861bd`,
отправлен в `origin/main`, подтверждён чистый status. Этап 17: серверное публичное
расписание GROUP, явная публикация OWNER, общее публичное имя в TrainerProfile.
Пользователь выполнил 169/169 тестов на отдельной ideal_auth_test до последнего
UI-дополнения отмены/удаления; после дополнения подтвердил интерфейс, нового полного
вывода npm test не предоставлял. Миграция этапа 17 применена к ideal_dev, схема актуальна;
по сравнению снимков прежние данные 24 таблиц совпали. Это не проверка восстановления backup.

Этап 18 реализован в ZIP-патче и ожидает локальных PostgreSQL-проверок и приёмки:
публичный каталог и отдельные профили тренеров из CRM, публикация и фото только OWNER.
Правила — [TRAINERS.md](docs/TRAINERS.md), применение —
[DEVELOPMENT.md](docs/DEVELOPMENT.md#этап-18-публичные-тренеры).
Новая миграция `20261025140000_public_trainers`, старые миграции не изменяются.

Домен не выбран, SEO_INDEXABLE по умолчанию false. Реальные материалы клуба,
телефоны, данные тренеров и юридические тексты ожидаются. Онлайн-запись и онлайн-покупка абонементов не подключены. В магазине по-прежнему
только самовывоз и оплата при получении. Установка PWA на телефоны/Safari и
системная доставка Push не подтверждены. Платформа не объявляется готовой к production.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000; вход сотрудников — /login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
