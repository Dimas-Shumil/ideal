# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–11 находятся в `origin/main`; последний архивный коммит документации — `41b6f4c`.
В текущем патче реализован этап 12: внутреннее расписание, запись, фактические посещения,
активация первым визитом, «Дуэт», подарочный зал и компенсации. До локальной приёмки и push
этап 12 не считать опубликованным в `origin/main`.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000/login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
