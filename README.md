# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–18 приняты пользователем. Последний подтверждённый commit — `7d7851d`,
отправлен в `origin/main`, подтверждён чистый status. Для этапа 18 пользователь
выполнил полный npm test на отдельной ideal_auth_test: 188/188 PASS без пропусков.
Миграции ideal_dev актуальны (8 миграций); сравнение количества строк и digest
прежних данных всех 24 таблиц успешно, включая publicName/publicVersion и публикации
занятий. Это сравнение не является backup или проверкой восстановления.

Этап 19 реализован в ZIP-патче и ожидает полного локального PostgreSQL-прогона,
dev-миграции со сравнением данных и приёмки. OWNER → «Контент сайта»: три публичных
направления, выбранный тренер главной, материалы «О клубе» и единые контакты.
Правила — [CONTENT.md](docs/CONTENT.md), применение —
[DEVELOPMENT.md](docs/DEVELOPMENT.md#этап-19-контент-сайта).
Новая миграция `20261025170000_public_content`; старые миграции неизменны.

Домен не выбран, SEO_INDEXABLE по умолчанию false. Реальные материалы клуба,
телефоны, данные тренеров и юридические тексты ожидаются. Онлайн-запись и онлайн-покупка абонементов не подключены. В магазине по-прежнему
только самовывоз и оплата при получении. Установка PWA на телефоны/Safari и
системная доставка Push не подтверждены. Платформа не объявляется готовой к production.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000; вход сотрудников — /login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
