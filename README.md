# ИДЕАЛ

Цифровая платформа спортивного клуба «ИДЕАЛ», Абакан. Разработка — ShumDev.

Публичные страницы: HTML, SCSS, vanilla JavaScript. Закрытые панели: Express 5,
EJS, PostgreSQL и Prisma 7.10.1. React не используется.

## Текущее состояние

Этапы 1–15 приняты пользователем и отправлены в `origin/main`.
Последний подтверждённый commit — `8f5bd7f`, включая публичную установку PWA.
Предыдущий Windows npm test — 138/138, это не результат этапа 16.

Этап 16 реализован в текущем патче, ожидает локальной проверки и приёмки:
серверный публичный прайс из CRM, публикация тарифов только OWNER, SEO с явным
включением индексации после выбора домена, canonical и единый адрес главной `/`.
Дополнение: OWNER удаляет тарифы и товары с подтверждением; старые абонементы и
заказы сохраняются. Фото можно добавить при создании товара; редактирование и
галерея доступны по явным ссылкам в списке.
Новая миграция основного этапа — `20261025090000_public_membership_plans`; порядок применения
и сравнение данных — [DEVELOPMENT.md](docs/DEVELOPMENT.md#этап-16-применение).

Домен не выбран, SEO_INDEXABLE по умолчанию false. Реальные материалы клуба,
телефоны, данные тренеров и юридические тексты ожидаются. Публичные расписание,
онлайн-запись и онлайн-покупка абонементов не подключены. В магазине по-прежнему
только самовывоз и оплата при получении. Установка PWA на телефоны/Safari и
системная доставка Push не подтверждены. Платформа не объявляется готовой к production.

## Запуск настроенного проекта

```bat
npm run dev
```

Открыть http://127.0.0.1:3000; вход сотрудников — /login, если этот адрес указан в существующей конфигурации.
Для серверных панелей нужен Node; Go Live подходит только публичной статической части.
