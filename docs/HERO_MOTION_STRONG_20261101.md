# ИДЕАЛ — заметнее движение в хиро

Накладывать поверх IDEAL_HERO_ATMOSPHERE_PATCH_20261101.zip. Предыдущие правки карточек и PWA сохранены.

Облака: размах увеличен с 9% до 24%, время прохода уменьшено с 48 до 20 секунд. Движение равномерное и начинается сразу с активной части цикла. Прозрачность слоя повышена с 0.5 до 0.82 днём и с 0.2 до 0.46 ночью.

Туман: размах увеличен с 14% до 30%, время прохода уменьшено с 32 до 14 секунд. Дневная плотность повышена с 0.3 до 0.65, ночная — с 0.18 до 0.42. Слой расположен выше, чтобы движение читалось у статуи.

Солнечное свечение меняется сильнее, время прохода сокращено с 16 до 7 секунд. Мерцание звёзд ускорено. Анимации по-прежнему отключаются при reduced motion и останавливаются вне хиро. Расписание дня и ночи по Абакану сохранено.

Изменяются четыре рабочих файла и добавляются два файла документации. CSS собран. Установка зависимостей и миграции не нужны. Этот дополнительный патч не меняет HTML и серверный код, поэтому отдельный перезапуск PM2 не требуется. Если предыдущий патч атмосферы ещё не развёрнут, примените оба и перезапустите PM2 для нового HTML.

## Проверка и коммит в Windows CMD

Перед распаковкой в корне проекта проверьте ветку, адреса и собственные изменения:

```bat
git status --short --branch
git branch --show-current
git remote -v
```

Распакуйте ZIP в корень с заменой. При ветке main и origin https://github.com/Dimas-Shumil/ideal.git:

```bat
git diff --check
node --check site/scripts/hero-atmosphere.js
node --test tests/hero-atmosphere.test.js tests/pwa-install.test.js tests/push-sw.test.js
git add --pathspec-from-file=docs/HERO_MOTION_STRONG_FILES.txt
git diff --cached --stat
git diff --cached --check
git diff --cached
git commit -m "Усилена анимация облаков, тумана и света в хиро"
git push origin main
git status --short --branch
```

Если предыдущий патч ещё не закоммичен, сохраните также его файлы по docs/HERO_ATMOSPHERE_PATCH_FILES.txt перед коммитом.

После применения откройте главную через Ctrl+F5. Дождитесь окончания вступления, затем наблюдайте 3–5 секунд. Настройка уменьшения движения в Windows/браузере сохраняет статичный вид намеренно.
