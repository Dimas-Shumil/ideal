# Публичный прайс и SEO — этап 16

## Публичные данные

Главная `/` выводит опубликованные активные тарифы CRM и товары серверного магазина.
Публичные тарифы выбираются по allowlist полей в `server/modules/public/plans.js`;
клиенты, платежи, сотрудники, версии и история CRM не отдаются в публичный HTML.
Управление прайсом: OWNER → Тарифы → Редактировать → «Показывать на сайте» и порядок.
Ни создание CRM-тарифа, ни сама миграция не публикуют его автоматически.
Изменённые данные видны после обновления страницы, не в реальном времени в открытой вкладке.

Главная остаётся no-store. JS не требуется для чтения тарифов: обе категории видны,
при включённом JS работают переключение, drag и клавиатура. Go Live — только превью
вёрстки: старых самостоятельных цен на главной больше нет. Публичное расписание подключается в этапе 17 отдельной безопасной выборкой.
Каталог тренеров остаётся демонстрационным; онлайн-записи и онлайн-продажи абонементов нет.

## Настройки

По умолчанию `SEO_ORIGIN` пустой, `SEO_INDEXABLE=false`: индексация запрещена,
robots.txt содержит Disallow: /, sitemap.xml — пустой валидный urlset без localhost.
При пустом SEO_ORIGIN абсолютные canonical/OG/JSON-LD не подставляются.
Новых секретов и обязательных настроек для локального запуска нет.

После выбора и подтверждения домена вручную задать в существующем .env:

- APP_ORIGIN — HTTPS origin выбранного домена;
- SEO_ORIGIN — тот же origin без пути, query и завершающего `/`;
- SEO_INDEXABLE=true — только после проверки контента и готовности публичных страниц;
- NODE_ENV=production — действующие production cookies/HTTPS/CSP сохраняются.

Не копировать примерный домен из тестов. В production несовпадение SEO_ORIGIN и
APP_ORIGIN, HTTP, localhost/IP или включение без домена останавливают запуск.
В development/test всегда noindex, даже при заполненных SEO-настройках.
Перед запуском реальной индексации — отдельная проверка на выбранном домене.

## URL и индексация

| URL | Поведение после включения SEO в production |
| --- | --- |
| `/` | Индексируемая главная, canonical `/` |
| `/index.html` | 301 на `/`, query сохраняется; браузер сохраняет fragment |
| `/shop.html` | Индексируемый каталог |
| `/shop.html` с параметрами | noindex,follow; canonical основного каталога |
| `/product.html?id=UUID` | Активный товар индексируется, canonical с этим id |
| `/product.html` без id | Страница выбора товара, noindex |
| Неизвестный/выключенный товар | HTTP 404, noindex |
| `/about.html`, `/trainers.html`, `/trainer.html` | noindex до получения и проверки реальных материалов |
| Главная с query | noindex,follow; canonical `/` |
| Корзина, заказ/результат, вход, кабинеты, API | noindex; прежние no-store и защита доступа сохранены |
| Неизвестная страница | HTTP 404, noindex |

Sitemap включает только `/`, `/shop.html` и активные товары. Нет сессионных URL,
фильтров, демо-профилей или выдуманных lastmod. Robots дополнительно закрывает
служебные пути. Robots/noindex не заменяют авторизацию и не являются защитой данных.
Все ответы получают X-Robots-Tag; готовые публичные страницы переопределяют его
согласованной политикой. Static preview HTML остаётся noindex.

## Метаданные

Title/description для главной, публичных информационных страниц и каталога;
название/описание товара — из серверного источника. Canonical и Open Graph берут
origin из конфигурации, а не Host запроса. Значения экранируются в HTML/EJS.
Минимальный JSON-LD WebSite на главной: только имя «ИДЕАЛ» и настроенный URL.
Его SHA-256 добавляется в CSP без unsafe-inline. Нет выдуманных отзывов, рейтингов,
биографий, достижений, телефонов и реквизитов. OG-картинка и расширенная разметка клуба
отложены до подтверждённых материалов. SEO не гарантирует позиции в поиске.

## Границы приёмки

Домен ещё не выбран; indexable=true проверялся через HTTP на тестовом домене,
без публикации и без обращения к поисковикам. Реальные материалы и юридические тексты
ожидаются. Работоспособность на реальном HTTPS/Nginx и индексация поисковыми системами
не подтверждены. Фактические проверки: [отчёт](archive/STAGE16_INTEGRATION.md).
