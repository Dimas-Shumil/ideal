# IDEAL / Hero + PWA — точечный патч 2026-11-01

- Смягчён нижний край двух исходных изображений фигуры через градиент прозрачности; фото **не содержит** полного тела и патч не дорисовывает отсутствующие части.
- По обновлённому решению статуя **видна только днём**; на закате плавно исчезает, ночью отсутствует, на рассвете возвращается. Дневная яркость не изменена.
- Плашка PWA уплотнена для телефонов и ПК, светлая днём и графитовая ночью по часам Абакана (UTC+7).
- Сохранены установка, закрытие, свайп, «Позже» и десятисекундная задержка.
- Исправления локальны: серверная БД, Prisma и зависимости не тронуты.

## Применение
Распакуйте ZIP поверх корня проекта с сохранением структуры каталогов. Перед копированием сохраните локальные изменения. Проверка: `node --check site/scripts/hero-atmosphere.js` и `node --check site/scripts/pwa-install.js`, затем тесты проекта (`npm test`) в установленной локальной среде.

**Ограничение:** для действительно полноценной статуи с ногами нужен новый оригинальный ассет, в текущем WebP ног нет. Изменения здесь делают переход к туману естественнее, не придумывая анатомию.
