## Реализация

Общий переиспользуемый компонент pwa-install.js/pwa-install.scss и готовый CSS.
Подключён к семи статическим страницам и серверным страницам магазина.
Это немодальный aside без переноса фокуса. Нативный prompt вызывается только
после клика; иначе показывается инструкция. Escape/«Позже»/отказ в нативном
диалоге сохраняют срок на семь дней. Закрытие синхронизируется между вкладками.
Standalone/appinstalled и сохранённая отметка установки скрывают плашку.
Браузер не всегда позволяет обнаружить уже установленное приложение из обычной
вкладки; удаление из ОС также не снимает сохранённую отметку автоматически.
При недоступном localStorage текущая страница продолжает работать.

Manifest start_url изменён с /login на /, название стало общедоступным.
id /employee-app сохранён, чтобы не создавать второе приложение. Ссылка
«Кабинет сотрудника» добавлена в источник общего футера и синхронизирована
штатным инструментом. Раздел /application сохраняет guards и вход сотрудников.
Единый SW /push-sw.js, Push и allowlist переходов сохранены. Собственный offline-кэш
повышен до v2; кэшируются по-прежнему только offline.html и pwa.css. Файлы плашки,
публичный HTML и серверные данные в кэш не добавлены. Нет очередей и повторов POST.
Никаких новых зависимостей, env, миграций и изменений бизнес-операций.

установленного приложения и системная доставка Push не выполнялись.
Публичные анимации полностью не регрессировались; исходные механики не менялись.
БД пользователя не подключалась и не изменялась.

ZIP содержит только новые/изменённые файлы относительно нового архива пользователя,
с путями от корня IDEAL. Удалений нет. Распаковать поверх проекта с заменой,
выполнить npm test (ожидается 138), затем npm run dev. Переустановка зависимостей
и миграции dev не нужны. .env/секреты/БД/node_modules/скриншоты в ZIP не включать.
В уже установленном приложении метаданные обновляет браузер в своём темпе;
принудительного перезапуска и skipWaiting нет. Этап 16 не начинался.
