# Магазин — оформление фильтра

25 октября 2026 года. Точечная правка по двум скриншотам пользователя.

- Подпись над полем категории, единая высота поля и основной кнопки, отступы.
- На desktop элементы выровнены по нижнему краю, на mobile поле занимает всю ширину,
  действия расположены следующей строкой, кликабельные области не меньше 44 px.
- Тёмная кнопка со светлым текстом, hover, active scale(.98), focus-visible,
  prefers-reduced-motion. Без CSS variables, :root, !important и дополнительных стрелок.
- Счётчик и пояснение отделены от формы, пустое состояние оформлено отдельным блоком.
- Готовый CSS скомпилирован из shop.scss. Новых зависимостей и миграций нет.

Проверено: 8 браузерных сценариев в Chromium 133/Linux — 320/390/768/1440 px,
JS включён/выключен. Проверены отсутствие горизонтального overflow, размеры элементов,
выравнивание и отступы, отправка GET-фильтра без JS и сохранение выбранной категории.
Визуально просмотрены desktop/mobile. Для этой проверки шаблон рендерился с пустым
каталогом и тестовыми категориями; бизнес-операции/БД и полный npm test не запускались.
Это не новая полная приёмка этапа 14. Скриншоты и временные QA-файлы в патч не входят.

ZIP содержит catalog.ejs, shop.scss, shop.css и этот отчёт. Распаковать поверх проекта
после основного патча этапа 14, затем обновить страницу с Ctrl+F5.
Миграции и npm ci для этой правки не нужны. Удаляемых файлов нет.
