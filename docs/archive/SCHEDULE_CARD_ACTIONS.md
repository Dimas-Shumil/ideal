# Действия в карточках расписания

25 октября 2026. Дополнение к этапу 17 по скриншоту пользователя.

Кнопка «Удалить» у отменённых занятий OWNER ведёт к существующей форме
подтверждения. Кнопка «Отменить» у запланированных OWNER/ADMIN ведёт к форме
причины отмены. TRAINER действий не получает. Без GET-мутаций, новых маршрутов,
миграций, зависимостей и изменений env. Посещения и аудит сохраняют прежнюю защиту.

EJS отрендерен с фикстурами OWNER/ADMIN/TRAINER: проверены видимость действий
по роли/статусу и ссылки на разделы подтверждения. SCSS скомпилирован штатным Sass.
Прежний полный локальный прогон пользователя до этого UI-дополнения: 169/169 PASS;
это не новый прогон дополнения. PostgreSQL и локальный браузер пользователя
в этой проверке не использовались. Функциональность сервиса удаления не менялась.

ZIP содержит только пять изменённых/новых файлов. Удалений нет. Распаковать поверх
проекта с заменой, перезапустить dev-сервер и обновить страницу.
