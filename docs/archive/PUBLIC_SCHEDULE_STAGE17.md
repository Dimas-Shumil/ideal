## Согласованный сценарий и результат

Отдельная `/schedule.html`, только просмотр GROUP. Текущая неделя и три следующих,
время Абакана UTC+7. Персональные занятия исключены. OWNER явно отмечает отдельные
экземпляры/будущие экземпляры серии и подтверждает публичную пригодность названий.
Пустое имя не заменяется внутренним displayName. Отмена остаётся видна, перенос
показывается на новой дате с прежним временем без причин. Пустые дни/недели,
неверный запрос и недоступность источника имеют разные состояния.

Минимальный DTO и allowlist select находятся в server/modules/public/schedule.js.
Новый публичный JSON API отсутствует. Страница смонтирована до middleware сессии:
сама не создаёт гостевую cookie. Внутренние страницы/API защищены независимо.
Новые OWNER-операции используют прежний механизм транзакций/доступа/версий/аудита.
Новая добавочная миграция: 20261025110000_public_schedule. Старые миграции неизменны.

Общие header/menu изменены в components и синхронизированы штатным Python tool;
новая публичная страница получает отдельные сгенерированные header/footer partials.
Исходники hero, Coverflow, drag, смены фона, каруселей и PWA не менялись.
Новые уникальные стили — public-schedule.scss и готовый CSS. На светлом фоне
уточнён цвет общей CTA-кнопки только в пределах новой страницы.

до тестовых случаев. Соединение pg с тестовым endpoint подтвердило ECONNREFUSED.

процессом. Никакой рабочий DATABASE_URL пользователя не использовался.

выбор конкретных экземпляров/чужая серия/версии/атомарность, replay и rollback

перенос/отмена/снятие публикации, отзыв сессии OWNER. Они синтаксически проверены,
но не выполнены. Ожидаемый полный набор: 169 случаев (прежние 153 + 16 новых).
