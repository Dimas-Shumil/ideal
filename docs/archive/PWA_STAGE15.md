# Этап 15 — PWA

25 октября 2026. Сценарий согласован пользователем перед изменениями.
Исходник — актуальный ZIP IDEAL; предыдущий подтверждённый commit 0a0d72f.

## Изменения

Одно приложение для сотрудников, старт /login, раздел /application для трёх ролей,
manifest, временные текстовые иконки any/maskable/Apple Touch, общий pwa-head.
Единый прежний /push-sw.js расширен offline fallback. Кэш содержит только
`/offline.html` и `/site/css/pwa.css`.
Push, notificationclick и allowlist сохранены. Установка не включает Push.
Обновление ждёт закрытия всех окон без skipWaiting/claim/reload. Обработчик статуса
учитывает, что registration.waiting может обновиться после события installed.
SW выдаётся без Last-Modified/ETag, чтобы проверки обновлений не зависели от секундной
точности файловой даты. Изменений бизнес-логики, зависимостей и БД нет.
README/ROADMAP приведены к подтверждённому состоянию этапа 14; PWA описана отдельно.

## Ограничения

Полный npm test вызван, но runner остановился ДО запуска наборов из-за отсутствия
TEST_DATABASE_URL. Локальный PostgreSQL в среде недоступен. Полные прежние 121 тест
в этой задаче заново не прогонялись; число 121/121 относится к предыдущей Windows-проверке
пользователя. Сохранены все прежние наборы, один тест SW-роута адаптирован под PWA,
добавлено 9 тестов, ожидаемый полный набор — 130.
БД пользователя не подключалась; миграций, dev-операций и нового сравнения digest нет.

Не выполнялись реальная установка ОС/телефона, Safari/iPhone, системная доставка Push,
проверка production HTTPS/Nginx и полная регрессия публичных анимаций/CRM/магазина.
Браузерные session-фикстуры не подтверждают PostgreSQL-сессии или authVersion в БД.
Приёмка полного набора и реальных устройств остаётся на локальной среде пользователя.
