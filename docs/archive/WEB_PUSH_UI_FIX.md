# Исправление управления Push на общем браузере

24 октября 2026 года. Дополнение к патчу этапа 13.

Кнопки вынесены в flex-контейнер с gap 12px, адаптивным переносом и явной
поддержкой hidden. Во время операции отображается статус, повторные клики блокируются.
При старой неподключённой подписке доступен явный сброс подписки браузера:
PushSubscription.unsubscribe(), затем ручное включение для текущего аккаунта.
Чужие серверные подписки не удаляются и не передаются другому пользователю.

Проверки: node --check, SCSS скомпилирован; Chromium на 1440/390/320 px:
конфликт регистрации 403 → сброс → новая подписка → успешное подключение,
видимость кнопок, отступы, отсутствие overflow и page errors. PushManager и API
в этих сценариях подменены. Мобильный скриншот визуально просмотрен.
Реальные системные разрешения/доставка не проверялись этим прогоном.
Полные 94 backend-теста повторно не запускались: backend/БД не менялись.

Применение: распаковать поверх IDEAL, перезапустить Node и обновить страницу Ctrl+F5.
Новые миграции и npm ci не нужны. Для одновременной работы OWNER/TRAINER использовать
разные браузеры или разные профили, обычные окна одного профиля разделяют сессию.
