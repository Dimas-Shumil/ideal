# Светлый интерфейс приложения ИДЕАЛ — 31.10.2026

Патч для текущего проекта с установленным серебряным логотипом v2.

## Изменения

- Страница входа: фотография зала слева, форма справа; на телефоне фотография над формой.
- Внутренние экраны: светлый серо-серебристый фон, графитовые кнопки, новые поля, карточки, таблицы и навигация с иконками.
- На экранах до 760px: нижняя навигация с тремя основными разделами и пунктом «Ещё». Набор ссылок соответствует роли владельца, администратора или тренера.
- Уведомления и установка приложения используют ту же палитру.

## Установка

1. Сделайте резервную копию проекта либо сохраните текущие изменения в Git.
2. Распакуйте содержимое архива в корень проекта, где находится package.json, с заменой файлов. Не создавайте дополнительную вложенную папку.
3. Если локальный сервер уже запущен, остановите его и выполните `npm run dev`. Если порт 3000 занят другим экземпляром, завершите этот экземпляр перед запуском.
4. Обновите страницу. Для установленного приложения полностью закройте и откройте его снова.

Новые зависимости и миграции базы не нужны. CSS уже собран. Исходник: `site/sass/app-ui-v1.scss`.

Для повторной сборки стилей при дальнейших изменениях:

```sh
npx sass --no-source-map site/sass/app-ui-v1.scss site/css/app-ui-v1.css
npx sass --no-source-map --style=compressed site/sass/app-ui-v1.scss site/css/app-ui-v1.min.css
```

После проверки локально закоммитьте файлы из `docs/APP_UI_PATCH_FILES.txt` и отправьте изменения в ветку, которую использует сервер. На сервере в `/var/www/ideal`: `git pull --ff-only`, затем `pm2 restart ideal`. Если уже есть незакоммиченные серверные изменения, сначала сохраните их.

## Проверки

- 45 целевых тестов: пройдены.
- Все 48 EJS-шаблонов компилируются.
- Содержимое исходной формы входа сохранено без изменений: action, поля, CSRF и ограничения ввода совпадают.
- Все 54 файла серверных модулей, middleware и Prisma совпадают с исходной версией.
- Для каждой роли проверено сохранение ссылок и выделения текущего раздела.
- В браузере проверены вход и расписание на настольном и мобильном размере, открытие меню «Ещё», отсутствие горизонтального переполнения мобильного экрана.

Браузерная проверка выполнена на реальных EJS-шаблонах с демонстрационными данными. Полные операции с рабочей базой, авторизация реальным пользователем, push-доставка и установка PWA на устройство в этой среде не проверялись.

У исходного проекта отдельно обнаружены три прежних падения тестов `club-phone-grid` / `public-ui-controls`, связанные с телефоном публичного сайта. Эти файлы и публичные страницы патч не меняет.
