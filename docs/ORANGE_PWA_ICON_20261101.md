# ИДЕАЛ — возврат оранжевой иконки приложения

Патч подготовлен поверх текущего проекта с анимацией хиро, версия 74133b1. Возвращает согласованную оранжевую иконку приложения из коммита 1cd0d7e. Оригинальные PNG перенесены без перерисовки под новыми именами orange-v3, чтобы браузеры распознали изменение URL иконок.

## Что изменилось

- Manifest ссылается на оранжевые иконки 192×192, 512×512 и отдельную maskable 512×512.
- У maskable непрозрачный тёмный фон на всю квадратную основу, которую Android обрезает под форму значка. Знак и надпись находятся в безопасной центральной области. Внутреннего белого квадрата нет.
- Apple Touch Icon 180×180 заменён во всех HTML и общих EJS-шаблонах, где он подключался.
- Плашка установки показывает оранжевую иконку.
- Логотип в шапке/подвале, favicon, изображения Open Graph и иконка Push-уведомлений сохранены. Идентификатор /employee-app, start_url, scope и настройки установленного приложения сохранены. Правки CRM, БД, .env, CSS и service worker отсутствуют.

Форма установленной иконки зависит от оболочки и настроек телефона: круг, скруглённый квадрат и другие маски. До краёв заполняется фон; обязательные отступы вокруг самого знака защищают его от обрезки.

## Применение в Windows CMD

Откройте CMD в корне проекта:

```bat
git status --short --branch
git branch --show-current
git remote -v
```

Ожидается main и origin https://github.com/Dimas-Shumil/ideal.git. Сначала сохраните собственные незакоммиченные изменения. Распакуйте ZIP в корень с заменой файлов.

```bat
git diff --stat
git diff --check
node --check site/scripts/pwa-install.js
node tools/check-brand.mjs
node --test tests/pwa.test.js tests/pwa-install.test.js tests/push-sw.test.js tests/hero-atmosphere.test.js
```

Для локальной проверки нужны уже установленные зависимости проекта. Новые пакеты для патча не требуются. Если приложение запущено, перезапустите его, затем откройте главную через Ctrl+F5. В DevTools → Application → Manifest должны отображаться пути orange-v3 и новая иконка.

## Сервер

```bash
cd /var/www/ideal
git status --short --branch
git branch --show-current
git remote -v
```

При чистой папке, ветке main и upstream https://github.com/Dimas-Shumil/ideal.git:

```bash
git fetch upstream &&
git merge --ff-only upstream/main &&
pm2 restart ideal &&
curl -fsS https://ideal-abakan.ru/health/live &&
curl -fsS https://ideal-abakan.ru/health/ready
```

Перезапуск нужен для обновлённого HTML главной, который загружается при старте приложения. Установка зависимостей и миграции не нужны.

## Уже установленное приложение

Новая установка получает новую иконку. Уже установленное приложение может предложить подтвердить смену значка; мгновенная замена на всех устройствах не гарантируется. Откройте приложение с интернетом, а затем проверьте доступное обновление. В Chrome может появиться пункт Review app update / просмотр обновления приложения. Поведение зависит от браузера и версии Android. На iPhone для смены значка может потребоваться повторное добавление на главный экран.

Вручную удалять приложение ради первой проверки не нужно. Если Android долго сохраняет старый значок, сначала пришлите скрин и уточните, из какого браузера приложение устанавливалось. Не очищайте данные браузера: это может удалить локальные настройки и подписку Push.

Справка Chrome: https://developer.chrome.com/blog/improvements-to-web-app-updates
