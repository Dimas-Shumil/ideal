# Фото страницы входа

Применяется поверх IDEAL_APP_LIGHT_UI_PATCH_20261031.zip.
Распакуйте в корень проекта с заменой файлов, перезапустите приложение и обновите страницу (Ctrl+F5).

Установлено ваше фото, сохранены его цвета. Левая часть занимает половину ширины экрана без внешнего отступа; фото заполняет всю площадь с пропорциональным кадрированием. На телефоне фото остается над формой.

Форма входа и серверная логика не изменены. CSS уже собран, установка зависимостей и миграции не требуются.
Проверено в браузере: фото загружено, левая граница 0px, ширина 50% экрана. Все 48 EJS-шаблонов компилируются.
