# ИДЕАЛ — живая атмосфера главного экрана

Патч подготовлен поверх версии d3550b2: исходный архив от 01.11.2026 с предыдущими патчами PWA, фотографий тренеров и высоты абонементов. Сохраняет прежнюю композицию, исходные изображения и вступление хиро.

Добавлены плавно движущиеся облака за статуей, туман снизу перед фигурой, мягкое солнечное свечение днём, ночное небо и мерцание звёзд. Ночной режим меняет цвета текста и верхнего хедера для читаемости. Остальные страницы не получают ночной режим.

## Время Абакана

Расписание декоративное, фиксированное, круглый год; оно не рассчитывает астрономический восход и закат. Часы устройства должны быть выставлены правильно; часовой пояс посетителя не влияет на режим.

| Время в Абакане (UTC+7) | Вид хиро |
| --- | --- |
| 00:00–07:30 | Ночь |
| 07:30–08:00 | Плавное осветление |
| 08:00–20:00 | День |
| 20:00–20:30 | Плавное затемнение |
| 20:30–24:00 | Ночь |

Время проверяется при открытии, раз в минуту и при возврате во вкладку. Изменения соседних минут смешиваются за 2 секунды. Переключение работает и у уже открытой страницы. Запросы к серверу, геолокация и внешние сервисы для этого не используются.

Облака и туман используют локальную SVG-текстуру; нет новых библиотек и видео. Анимации останавливаются вне первого экрана и в скрытой вкладке. При системной настройке уменьшения движения эффекты статичны. Без JS сохраняется дневной фон.

## Применение в Windows CMD

Из корня проекта перед распаковкой:

```bat
git status --short --branch
git branch --show-current
git remote -v
```

Ожидаются main, origin https://github.com/Dimas-Shumil/ideal.git и чистая рабочая папка. Собственные незакоммиченные изменения сначала сохраните. Распакуйте содержимое ZIP в корень с заменой файлов.

```bat
git diff --stat
git diff --check
node --check site/scripts/hero-atmosphere.js
node --test tests/hero-atmosphere.test.js tests/pwa-install.test.js tests/push-sw.test.js tests/static-site-and-photos.test.js
```

CSS собран. Если локальное приложение уже запущено, перезапустите его, затем откройте главную через Ctrl+F5. index.html читается приложением при старте.

Для проверки ночи днём можно в DevTools Console главной страницы временно выполнить:

```js
document.querySelector('.hero__night-sky').style.opacity = '1';
document.querySelector('.hero__stars').style.opacity = '1';
document.querySelector('.hero__sun').style.opacity = '0';
document.querySelector('.hero__foreground img').style.filter = 'brightness(.72)';
document.documentElement.classList.add('hero-night');
```

Это только предварительный просмотр: через минуту скрипт вернёт текущее время. Перезагрузка также возвращает автоматический режим. Исходные файлы и системные часы менять не нужно.

## Обновление production

На сервере сначала проверьте состояние и адреса:

```bash
cd /var/www/ideal
git status --short --branch
git branch --show-current
git remote -v
```

Если папка чистая, ветка main и upstream указывает на Dimas-Shumil/ideal:

```bash
git fetch upstream &&
git merge --ff-only upstream/main &&
pm2 restart ideal &&
curl -fsS https://ideal-abakan.ru/health/live &&
curl -fsS https://ideal-abakan.ru/health/ready
```

Для этого патча нужен перезапуск PM2, поскольку изменён index.html. npm install и миграции не нужны. База, .env, пользователи, CRM, платежи, расписание и обработчики Push не менялись.
