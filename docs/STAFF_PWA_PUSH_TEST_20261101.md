# IDEAL — тестовое Push-уведомление для сотрудника

Дополнение к `IDEAL_STAFF_PWA_REMEMBER_20261101.zip`.

- На `/notifications` после включения уведомлений появляется кнопка проверки.
- Сообщение отправляется через существующий `PushDelivery` и worker
  только на текущую подписку вошедшего OWNER/ADMIN/TRAINER.
- Ограничение запросов: пять за 15 минут, повторное нажатие в ту же минуту
  не создаёт новую доставку.
- Проверка авторизации, сессии и CSRF; нельзя адресовать тест другому аккаунту.
- Очередь не гарантирует доставку: её необходимо проверить на устройстве.
- `.env`, БД/Prisma, зависимости, существующая подписка и PWA не меняются.

При применении распаковать поверх уже установленного патча PWA сотрудников.
Для быстрой проверки: `node --check server/modules/push/service.js`,
`node --check server/modules/push/routes.js`,
`node --check site/scripts/notifications.js`.
Интеграционный тест `node --test tests/push.test.js` требует отдельно
настроенной тестовой PostgreSQL БД с `NODE_ENV=test`.
